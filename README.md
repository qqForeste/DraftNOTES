# DraftNOTES
A Full Stack Performance Review Platform
Made With HTML, CSS, React, TypeScript and Vite for Frontend.
Deployed using Cloudflare pages, PostgreSQL database and AWS
Uses actual REST APIs from Official Riot API

The project is live at: https://draftnotes.lol/

For recruiters:
As this website is in live production, I kept the code closed source to protect the security of the users, however I welcome any requests to review the code during an interview.

Full Documentation is soon to be added.
